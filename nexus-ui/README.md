# Nexus UI

This is the frontend for the Nexus trading engine.

## Demo Server Cold Start

> **Note**: The backend demo is hosted on Render's free tier. The free tier spins down the server when idle.
> **If you are visiting the demo for the first time or after a period of inactivity, the first request may take 30–60 seconds to complete or time out.** 
> Please be patient while the server wakes up.
